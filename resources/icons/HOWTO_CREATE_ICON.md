# Інструкція для створення іконки ASM

## Швидкий спосіб (Рекомендовано)

### Крок 1: Відкрийте онлайн конвертер
Перейдіть на один з цих сайтів:
- https://convertio.co/svg-ico/
- https://cloudconvert.com/svg-to-ico
- https://anyconv.com/svg-to-ico-converter/

### Крок 2: Завантажте SVG
Завантажте файл `icon.svg` з цієї папки

### Крок 3: Налаштуйте параметри
- Виберіть розміри: 16x16, 32x32, 48x48, 64x64, 128x128, 256x256
- Формат: ICO (Windows Icon)

### Крок 4: Завантажте результат
Збережіть файл як `icon.ico` в цю папку `resources/icons/`

## Альтернативний спосіб (якщо є Python)

```bash
# Встановіть необхідні бібліотеки
pip install Pillow cairosvg

# Запустіть скрипт конвертації
python convert_svg_to_ico.py
```

## Якщо потрібно швидко протестувати

Для швидкого тестування можна використати будь-яку існуючу .ico іконку:
1. Знайдіть будь-який .ico файл
2. Перейменуйте його на `icon.ico`
3. Помістіть в папку `resources/icons/`
4. Перезберіть проєкт

## Після створення icon.ico

1. Переконайтесь, що `icon.ico` знаходиться в `resources/icons/icon.ico`
2. Пересоберіть проєкт:
   ```bash
   cd build
   cmake --build . --config Release
   ```
3. Іконка автоматично з'явиться у:
   - Системному треї
   - Виконуваному файлі .exe
   - Ярлику програми

## Опис іконки

- **Фон**: Синій круг (#2563eb)
- **Центр**: Білий динамік зі звуковими хвилями
- **Верх**: Літери "ASM"
- **Низ**: Стрілки перемикання (←→)
