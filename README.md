# AudioSwitchManager

**AudioSwitchManager** — продуктивна та легка десктопна утиліта для Windows, яка дозволяє швидко керувати аудіопристроями через системний трей та глобальні гарячі клавіші.

## ✨ Особливості

### 🎧 Управління аудіопристроями
- Швидке перемикання між пристроями відтворення (навушники, колонки)
- Управління пристроями запису (мікрофони)
- Відображення поточного активного пристрою в меню
- Перемикання через WASAPI (Windows Audio Session API)

### ⌨️ Глобальні гарячі клавіші
- **Ctrl + Alt + PageDown** — перемикання на наступний пристрій відтворення
- **Ctrl + Alt + PageUp** — перемикання на попередній пристрій відтворення
- Повністю налаштовувані комбінації клавіш через конфігураційний файл

### 🔊 Профілі гучності процесів
- Автоматичне встановлення рівня гучності для конкретних додатків
- Приклад: Discord завжди на 80%, браузер на 50%
- Перевірка та застосування правил кожні 2 секунди
- Збереження налаштувань у JSON

### 🖱️ Системний трей
- Мінімалістичний інтерфейс у треї
- Контекстне меню з повним списком пристроїв
- Сповіщення при зміні пристроїв
- Легкий доступ до всіх функцій

## 💻 Системні вимоги

- **ОС:** Windows 10/11 (64-bit)
- **Компілятор:** MSVC 2019 або новіший


## 🚀 Використання

### Перший запуск

1. Запустіть `AudioSwitchManager.exe`
2. Програма з'явиться в системному треї (біля годинника)
3. З'явиться сповіщення про успішний запуск

### Перемикання пристроїв

**Через гарячі клавіші:**
- Натисніть `Ctrl + Alt + PageDown` для перемикання на наступний пристрій
- Натисніть `Ctrl + Alt + PageUp` для перемикання на попередній пристрій

**Через меню треї:**
1. Клацніть правою кнопкою миші на іконку в треї
2. Виберіть розділ "📢 Пристрої відтворення" або "🎤 Пристрої запису"
3. Клацніть на потрібний пристрій
4. Поточний активний пристрій відмічений символом ✓

### Налаштування гучності процесів

Відредагуйте файл конфігурації `%APPDATA%\AudioSwitchManager\config.json`:

```json
{
  "processVolumes": [
    {
      "processName": "Discord.exe",
      "volume": 0.8
    },
    {
      "processName": "chrome.exe",
      "volume": 0.5
    },
    {
      "processName": "spotify.exe",
      "volume": 0.6
    }
  ]
}
```

Після редагування виберіть "🔄 Перезавантажити конфігурацію" в меню треї.

## ⚙️ Конфігурація

### Розташування файлу конфігурації

Конфігураційний файл знаходиться за адресою:
```
%APPDATA%\AudioSwitchManager\config.json
```

### Структура config.json

```json
{
  "processVolumes": [
    {
      "processName": "назва_процесу.exe",
      "volume": 0.8
    }
  ],
  "hotkeys": [
    {
      "id": 1,
      "modifiers": 6,
      "vk": 34,
      "action": "next_playback",
      "description": "Наступний пристрій відтворення"
    }
  ],
  "deviceProfiles": [
    {
      "name": "Робоче місце",
      "playbackDeviceId": "{0.0.0.00000000}.{device-id}",
      "captureDeviceId": "{0.0.1.00000000}.{device-id}"
    }
  ]
}
```

### Параметри гарячих клавіш

**Модифікатори (можна комбінувати через +):**
- `1` — MOD_ALT
- `2` — MOD_CONTROL
- `4` — MOD_SHIFT
- `8` — MOD_WIN

**Коди віртуальних клавіш (vk):**
- `33` — VK_PRIOR (PageUp)
- `34` — VK_NEXT (PageDown)
- `112-123` — F1-F12
- Повний список: [Microsoft Virtual-Key Codes](https://learn.microsoft.com/en-us/windows/win32/inputdev/virtual-key-codes)

## 🏗️ Архітектура

Проєкт розділений на модульні компоненти:

```
AudioSwitchManager/
├── include/
│   ├── AudioEngine.h           # WASAPI інтерфейс для керування аудіо
│   ├── TrayManager.h           # Системний трей та контекстне меню
│   ├── HotkeyManager.h         # Реєстрація глобальних гарячих клавіш
│   ├── ProcessVolumeManager.h  # Управління гучністю процесів
│   └── Config.h                # Читання/запис конфігурації JSON
├── src/
│   ├── AudioEngine.cpp
│   ├── TrayManager.cpp
│   ├── HotkeyManager.cpp
│   ├── ProcessVolumeManager.cpp
│   ├── Config.cpp
│   └── main.cpp                # Точка входу, ініціалізація компонентів
├── resources/
├── CMakeLists.txt
└── README.md
```

### Основні модулі

#### AudioEngine
Використовує WASAPI для:
- Перерахування активних пристроїв відтворення та запису
- Отримання дружніх назв пристроїв
- Зміни пристрою за замовчуванням
- Управління гучністю пристроїв

#### TrayManager
Керує системним треєм:
- Створення іконки в треї
- Відображення контекстного меню
- Показ системних сповіщень (toast notifications)

#### HotkeyManager
Реєстрація та обробка глобальних гарячих клавіш через Win32 API.

#### ProcessVolumeManager
Застосовує правила гучності до конкретних процесів через Audio Session API:
- Моніторинг запущених аудіосесій
- Автоматичне встановлення заданої гучності
- Періодична перевірка (кожні 2 секунди)

#### Config
Зберігає та завантажує налаштування у форматі JSON через nlohmann/json.
